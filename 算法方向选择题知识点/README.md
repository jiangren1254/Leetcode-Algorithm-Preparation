交叉验证方法的执行时间主要取决于需要进行的训练和测试次数。当样本量为1000时，我们可以分析各种方法需要的计算量：

留一法(b)需要进行1000次训练和测试，因为每次留出一个样本作为测试集，其余样本作为训练集。

2次5折交叉验证(d)需要进行2×5=10次训练和测试。
